# Contribuir a Luma

1. Crea un fork y trabaja en una rama dedicada a un cambio.
2. Mantén los módulos ES y usa nombres descriptivos. Evita dependencias nuevas si basta con una API existente del navegador.
3. Para fórmulas, registra los alias en el plugin, conserva la evaluación perezosa cuando corresponda y usa los errores del motor. Incluye pruebas para referencias, rangos, valores vacíos y entradas inválidas.
4. Ejecuta las pruebas del repositorio y prueba los flujos de interfaz que cambies con teclado y con entrada táctil cuando corresponda.
5. Abre un Pull Request con el propósito del cambio, pasos de verificación y cualquier limitación de compatibilidad.
